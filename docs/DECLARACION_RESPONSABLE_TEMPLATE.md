# Borrador para el productor — NO SUSCRITO

No es una declaración de conformidad. No publicar ni firmar hasta completar la
validación oficial, revisión normativa experta y las evidencias del producto exacto.
Ninguna identidad, fecha, firma ni afirmación de cumplimiento se rellena ficticiamente.

Referencia: [modelo orientativo AEAT v0.5.1](https://sede.agenciatributaria.gob.es/static_files/Sede/Tema/IVA/Verifactu/EjemplosDeclaracionResponsable(V0.5.1).pdf).

| Campo para completar y revisar | Valor / evidencia |
|---|---|
| Producto y código | BeautyTPV / BT; confirmar identificador definitivo |
| Versión exacta y SHA-256 de distribución | [pendiente] |
| Productor: identidad, NIF y domicilio de contacto | [pendiente] |
| Componentes y funcionalidades de esta versión | [inventario revisado y dependencias] |
| Modalidad y capacidad de obligados | [revisar diseño y valores declarados en XML] |
| Firma de registros cuando corresponda | [determinar aplicabilidad] |
| Afirmación normativa que debe suscribir el productor | [redactar tras revisión experta; no afirmada aquí] |
| Lugar y fecha de suscripción | [pendiente] |
| Representante competente y firma | [pendiente] |
| Contacto adicional, publicación e histórico de versiones | [pendiente] |
| Anexos de implementación y pruebas oficiales | [pendiente] |

El productor debe contrastar la normativa vigente y adaptar el documento al producto
entregado; este borrador no sustituye el modelo oficial ni la revisión fiscal.
