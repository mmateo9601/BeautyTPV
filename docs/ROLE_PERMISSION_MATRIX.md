## Decisiones y restricciones expresas

- Apertura de turno por Employee se conserva de V1 existente; cierre, arqueo y movimientos requieren Manager. La nueva peticion no prohibe expresamente apertura a Employee y exige no eliminar funcionalidades.
- Administracion del equipo es operacion interna jerarquica; la autorizacion PII independiente protege clientes, cuentas y documentos comerciales, no impide crear el primer administrador.
- Incidencias no admiten datos personales ni logs/XML/secretos. Sus patrones rechazan identificadores conocidos, pero no son un clasificador universal: el operador debe describir el problema sin nombres ni datos identificables.
- Acciones de restauracion/actualizacion real exigen permisos OS, parada de servicio y lock exclusivo; la web prepara/verifica y explica el procedimiento, sin shell arbitrario.
- AEAT, dispositivos fisicos y equipo destino siguen BLOQUEADO EXTERNO.
